# Auto Parts Catalog (Car Parts Web App)

> An interactive web application for browsing, filtering, and reviewing an automotive spare parts catalog.

## About the Project
This project is an interactive front-end web application designed to explore auto spare parts. It features dynamic data fetching from local JSON/API sources, vanilla JavaScript DOM manipulation, advanced filtering options, and a user review module.

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Data Source:** JSON (`pieces-autos.json`)
* **Environment & Tools:** Node.js, Git / GitHub

## Key Features
* Dynamic catalog rendering based on structured JSON data.
* Advanced filtering system (by price, category, availability).
* Customer review and rating management system (`avis.js`).
* Responsive and clean user interface styled with custom CSS.
